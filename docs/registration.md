# 自助注册（v0.5.0）

本功能从 v0.5.0 开始提供。

管理员仍须在服务器使用 `init-admin` 初始化。公开注册始终创建普通用户，不能指定管理员角色。注册填写用户名、密码和确认密码，无需邮箱。用户名为 3–48 个字符，密码为 12–128 个字符；忘记密码由管理员重置。

## 本地验证码

使用 ALTCHA 3.4.1 前端组件及官方 altcha 2.3.0 Python 库。前端 JavaScript、样式、中文语言和计算 worker 都从本实例加载，不请求第三方验证码服务。

Flask 签发限时 120 秒的 SHA-256 工作量证明挑战。浏览器计算结果经服务器验签后仅能使用一次，并绑定本次请求的来源地址。发放挑战与注册另有限流。它提高批量滥用的成本，不能保证识别人类或阻止有资源的自动化攻击者。

注册验证需要浏览器 Web Crypto 的安全上下文：公网和 NAS 普通 IP 访问请使用 HTTPS；本机开发可以使用 localhost 或 127.0.0.1。局域网明文 IP 地址访问时仍可登录已有账号，但注册页会提示改用 HTTPS。

## 开启或关闭

Compose 环境变量 `MOON_ALLOW_REGISTRATION=1` 开启自助注册（默认值），设置为 `0` 关闭。关闭时登录页隐藏入口，注册页面和 API 一并关闭；管理员创建用户的功能继续可用。

如在反向代理后运行，应用对注册和挑战同时设置来源地址及全局限流；默认不信任客户端提供的转发 IP。反向代理环境可能共用同一个来源地址配额。可按部署需求在代理设置额外限流，勿直接信任公网传入的 X-Forwarded-For。

## 常用位置与旧数据

八个新预设使用明确的 `xuezhi_group1_amap` 至 `xuezhi_group8_amap` 标识，坐标为高德 GCJ-02，不做第二次转换。旧标识 `xuezhi_group3` 及其中文引用统一指向新的学知三组团。已有网页账号在升级时自动迁移，不改变凭据、归属、自动计划和执行时间；旧版地址默认文字移除后按新坐标解析。手动坐标、坐标系、位置命名和地址文字覆盖功能继续保留。
