# 提交诊断（本地修复版 v0.5.1）

运行记录增加“提交行为”和“查看详情”。“首次提交”表示进入当天首次提交尝试，“仅复查”表示只读取学校记录，没有再次发送打卡 POST。“未提交”表示未进入提交步骤；升级前无法确定行为的记录显示“旧记录未区分”。

详情保留原始提交的 HTTP 状态、学校业务码、脱敏消息，以及本次每次复查的状态。接口返回成功不等于已签到，仍须回读学校记录确认。提交错误和复查错误分别保存，后续仅复查会引用当天首次尝试信息。

学校错误文字在持久化前隐藏已知凭据、学号、指纹、Cookie/Token、链接、邮箱和长标识；不保存原始响应体、请求头或 Cookie 值。详情接口沿用原有用户隔离：管理员可查看全部，普通用户只能查看自己的账号。

原有当日提交标记、自动计划和防重复保护保留。无法从升级前的记录恢复原始错误，不补造历史信息。此次修复增加持久化诊断，不清除已有 unknown 标记，也不自动重发不明确的提交。

提交异常还会输出同样经过脱敏的结构化容器日志，包含 jobId、提交行为、HTTP/业务码和错误类型；持久化数据库详情不依赖容器日志轮转保留。
